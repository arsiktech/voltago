# Volta Go design tokens

One set for the iOS app. SF and Dynamic Type. No second font.

## Color

| Token | Light | Dark |
| --- | --- | --- |
| canvas | `#F5F6F4` | `#0B0F0D` |
| surface | `#FFFFFF` | `#141A17` |
| raised | `#EEF0EE` | `#1B221F` |
| ink | `#0E1512` | `#EDF1EE` |
| muted | `#5A6560` | `#9AA59F` |
| line | `#8B948F` | `#8E9993` |
| action | `#0E1512` | `#646F6A` |
| action label | `#FFFFFF` | `#FFFFFF` |
| go | `#0D7D40` | `#21D277` |
| check | `#986200` | `#F0B429` |
| verify | `#426AC3` | `#7AA2F7` |
| danger | `#D83A40` | `#FF6B70` |

Green is only Go. Decision pills use ink on a tint, or white on a solid Go fill.

## Type

| Use | Style |
| --- | --- |
| Screen title | `.title3.bold` |
| Name | `.headline` |
| Price | `.title2.rounded.bold` |
| Fact | `.subheadline` |
| Meta | `.footnote.semibold` |
| Badge | `.caption.semibold` |

No fixed point sizes in the interface. Map pills use `.caption`.

## Space

4, 8, 12, 16, 24. Screen gutter and card padding are 16.

## Radius

9 badge, 14 control, 18 card. Chips and pills are capsules.

## Copy

A screen’s heading is its purpose. Do not add a slogan under it.
