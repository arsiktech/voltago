# Module: Data Artifacts

Data artifacts are file-backed inputs, caches, and evidence outputs that the
server and QA harness rely on.

## Responsibilities

- Provide source-backed lead records to the API.
- Keep manual leads separate from generated intelligence.
- Retain source-probe evidence for public-surface decisions.
- Store QA definitions, run evidence, canary histories, and manual proof status.

## Key Files

- [data/free_intelligence.json](../../../data/free_intelligence.json) - generated
  intelligence database.
- [data/seed_leads.json](../../../data/seed_leads.json) - hand-curated manual
  leads.
- [data/cache](../../../data/cache) - ingestion/runtime cache files.
- [data/source_probe](../../../data/source_probe) - saved public-surface evidence.
- [qa/features.csv](../../../qa/features.csv) - feature inventory.
- [qa/test-cases.csv](../../../qa/test-cases.csv) - test-case ledger.
- [qa/defects.csv](../../../qa/defects.csv) - defect ledger.
- [qa/*-latest.json](../../../qa) - regenerated evidence reports.
- [qa/*-history.jsonl](../../../qa) - bounded canary/link history.

## Public API

Data files are consumed through server/script functions rather than exported as
libraries:

- `load_intelligence_meta()`
- `load_intelligence(bbox=None)`
- `load_seed_leads()`
- `load_all_leads(bbox=None)`
- QA builders such as `qa_artifact_integrity.build_report()` and
  `qa_completion_audit.build_report()`.

## Internal Structure

The server mtime-caches raw intelligence JSON and normalizes only in-viewport
records when possible. QA CSV/JSON artifacts form a contract: the suite and
artifact-integrity checks validate shape, cross-references, counts, manual gates,
and latest reports.

## Dependencies

- **Uses:** generated JSON, CSV ledgers, public-source cache/probe files.
- **Used by:** backend API, ingestion, QA regression suite, completion audit.

## Notable Patterns / Gotchas

- `qa/*-latest.json` should be regenerated by scripts, not edited by hand.
- `data/source_probe` should not be deleted casually; it documents why some apps
  are linked/attributed instead of scraped.
- The Docker image intentionally excludes `qa`, `tests`, `docs`, caches, and
  probes via [.dockerignore](../../../.dockerignore).
