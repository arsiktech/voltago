# Volta Go iOS icon exploration — 2026-07-18

Eight intentionally different App Store directions, generated as concept masters before
vector reconstruction in Apple Icon Composer. These files do not replace the canonical
`ios/Volta/Volta/AppIcon.icon` package.

1. **Electric Runway** — route corridor, bolt, and forward arrow in one diagonal signal.
2. **Solar Compass** — Mediterranean sun disc and a decisive energy compass needle.
3. **Glass G-Pin** — continuous folded G/pin ribbon with a separate energy shard.
4. **Topographic Pulse** — layered terrain contours crossed by a live route pulse.
5. **Charge Gauge** — range/energy instrument with a clear green GO zone.
6. **Brutalist GO Cut** — high-contrast wayfinding arrow cut by a lightning void.
7. **Ceramic Waystone** — tactile route monument with a carved energy path.
8. **Refracted Portal** — a clear route ray passing through a glass navigation gateway.

## Iterations

- `01-electric-runway-v2-plain-ios.png` — front-facing, plain iOS treatment of concept 1:
  simplified flat geometry, restrained depth, no neon, chrome, or dramatic perspective.
- `electric-runway-plain-ios-iterations/` — ten creative branches from the plain-iOS
  treatment, each preserved as a source PNG and an opaque 1024 × 1024 App Store master:
  Negative-Space Wing, Ribbon Turn, Orbit Exit, Split Lane, Folded Route, Night Signal,
  Signal Nodes, Cutout Tile, Route Wave, and Corner Sprint.

## Status

Concept exploration only. Before adopting a direction, reconstruct it as simple SVG layers,
annotate Default/Dark/Mono appearances in Icon Composer, and test at small Home Screen and
App Store sizes. The current production icon remains unchanged.
